# 通用件查询工具

一个基于 Python + Tkinter 的本地查询工具，支持：

- 从 Excel 读取通用件数据
- 按动态字段组合查询
- 维护“类型 -> Excel/图标”映射
- 图形界面查询与命令行查询两种模式

## 1. 环境准备

1. 安装 Python（建议 3.11+）
2. 安装依赖：

```bash
pip install -r requirements.txt
```

## 2. 启动方式

### 2.1 图形界面（默认）

```bash
python query_tool.py
```

说明：
- 启动后默认打开 GUI
- 主窗口会在屏幕中间偏上显示
- 先选择“类型”，再点击“加载”读取对应 Excel

### 2.2 命令行交互模式

```bash
python query_tool.py --cli
```

### 2.3 命令行直接查询

按旧参数查询：

```bash
python query_tool.py --excel "杠铃汇总.xlsx" --diameter 20 --length 1200
```

按动态字段查询（可重复传参）：

```bash
python query_tool.py --excel "杠铃汇总.xlsx" --field 直径 --value 20 --field 长度 --value 1200
```

### 2.4 运行自检

```bash
python query_tool.py --self-check
```

## 3. GUI 使用方法

1. 打开程序
2. 在顶部“类型”下拉框选择类型
3. 点击“加载”读取该类型绑定的 Excel 数据
4. 在查询条件区域输入一个或多个条件
5. 点击“查询”查看结果
6. 结果表支持右键按列复制

## 4. 设置功能与口令

进入“设置”窗口需要口令。

- 设置口令：`2233`

设置窗口可进行：
- 新增/更新类型（名称、Excel 文件路径、图标路径）
- 删除类型

## 5. 打包（可选）

可使用批处理脚本打包：

```bat
build_exe.bat
```

或直接使用 PyInstaller（示例）：

```bash
python -m PyInstaller --noconfirm --clean --windowed --name "通用件查询工具" --icon "tool.png" --add-data "tool.png;." --add-data "types_config.json;." "query_tool.py"
```

## 6. 注意事项

- Excel 标题行必须包含“编码”和“所属项目”，且顺序必须是“编码”在前、“所属项目”在后。
- 可查询字段定义为“编码”和“所属项目”之间的列。
- 类型配置文件为 `types_config.json`，支持签名校验。建议只通过程序内“设置”修改，不要手工编辑。
- 图标建议使用 PNG，程序会按界面规则缩放显示。
- 如果出现“加载失败”，请优先检查：
  - Excel 路径是否存在
  - 文件是否被其他程序占用
  - 标题行是否符合要求

## 7. 首次使用流程（建议）

可按下面流程快速完成首次配置：

1. 双击启动程序（或运行 `python query_tool.py`）。
2. 点击“设置”，输入口令 `2233`。
3. 点击“新增/更新”，填写：
4. 名称（例如：杠铃）。
5. Excel 文件路径（选择你的数据文件）。
6. 图标路径（可留空，留空时使用默认图标）。
7. 关闭设置窗口，回到主界面。
8. 在“类型”下拉框选择刚配置的类型。
9. 点击“加载”，确认状态栏出现“已加载类型”。
10. 输入查询条件并点击“查询”。


## 8. 发布给同事使用（免 Python）

如果同事电脑没有 Python，建议直接发打包后的 `exe`。

打包人操作：

1. 在项目目录运行 `build_exe.bat`。
2. 打包完成后，进入 `dist` 目录。
3. 将以下内容一起发给同事：
4. `通用件查询工具.exe`（或 `dist/通用件查询工具/` 整个目录，取决于打包模式）。
5. `tool.png`（如果你的打包模式或资源策略需要外置图标）。
6. `types_config.json`（可选，预置类型配置时一起发）。

同事端注意：

1. 首次运行若被系统拦截，请在安全提示中选择“仍要运行”（企业安全策略以公司要求为准）。
2. 建议把 `exe` 放在固定目录，避免路径变化导致 Excel 路径失效。
3. 如需改类型配置，进入“设置”并使用口令 `2233`。

## 9. 常见问题

### Q1：为什么切换类型后图标不立刻变化？
当前逻辑是“点击加载并成功后”才更新为已加载类型图标，用于避免误判。

### Q2：为什么提示配置被篡改？
可能是配置文件格式不正确、签名不匹配或被手工改动。建议通过程序“设置”重新保存一次配置。
